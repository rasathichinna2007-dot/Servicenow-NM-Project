# Import Data using Transform Maps (Spreadsheet)

## Project Description

This project demonstrates how employee data from a spreadsheet can be imported into ServiceNow using Import Sets and Transform Maps. The project includes field mapping, data transformation, validation, duplicate prevention, and reporting.

## Objectives

- Import employee data from a spreadsheet into ServiceNow.
- Create and use an Import Set Table.
- Configure a Transform Map.
- Map source fields to target fields.
- Transform and validate the imported data.
- Prevent duplicate records using Coalesce.
- Create reports and dashboards for the imported data.

## Technologies Used

- ServiceNow
- Google spreadsheet
- Import Sets
- Transform Maps
- ServiceNow Reports & Dashboards
